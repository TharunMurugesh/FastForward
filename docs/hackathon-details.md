# Build What's Next with PayPal and AI: hackathon details

Organised from `docs/details.txt` (pasted from the Devpost page on 19 Oct 2026). Notes marked **[Sara]** are
our own reading, not Devpost's words.

**Deadline:** 12 Nov 2026 PT = 13 Nov 03:30 IST **[Sara: from our earlier notes; not in the pasted text, confirm on Devpost]**

## 1. The challenge

- Global online hackathon. No set problem statements, no tracks. Agents, apps, automations, payment
  experiences, business tools, anything.
- **The one fundamental rule: the project must meaningfully use both PayPal and AI.**
- Individual or team. New project, or an existing one with meaningful progress made during the hackathon.

## 2. What to build (project requirements)

Build or update an application that integrates the **PayPal developer platform (free sandbox)** with an AI
tool, model or platform of your choice. The project must:

1. Meaningfully integrate at least one PayPal technology, API, SDK, product or developer capability.
2. Meaningfully incorporate AI into the experience or functionality.
3. Demonstrate a working prototype or proof of concept.
4. Be documented well enough for judges to understand and evaluate it.
5. Comply with the Official Rules **[Sara: not in the pasted text; we have not read them]**.

Any AI tool is allowed, as long as PayPal integration is central. Sponsor tools are optional.

## 3. What to submit

| Item | Requirement |
|---|---|
| Project | Built with the required tools, meets section 2 |
| Text description | The project's features and functionality |
| Functional demo | Judges must be able to run or use a working build: **either** complete setup/run instructions in the repo **or** a hosted demo URL. Mockups, static prototypes and non-working demos do not count. |
| Tools | Which AI models/services were used, and how |
| Code repository | Public, on GitHub, GitLab or Bitbucket. All source, assets and run instructions. **Open source, with the licence visible at the top of the repo (About section).** |
| Demo video | **Under 3 minutes** (judges need not watch past that). Shows the project working on the device it was built for. **Public on YouTube**, link on the form. No third-party trademarks or copyrighted music/material without permission. |

## 4. Judging criteria

No weights are given.

| Criterion | The judges' question |
|---|---|
| Technological implementation | How thoroughly and skilfully does it use the PayPal Developer Platform and AI? Genuine effort, working, non-trivial? |
| Design | A complete, coherent product experience, not just a technical proof of concept? |
| Potential impact | A credible, specific case for a real problem and a real audience, and does the demo show it being solved? |
| Innovation / idea | How creative and novel, and how does it differ from existing concepts? |
| Presentation | Does the video show it working end to end? Does the pitch say what problem, for whom, and why it matters? Easy to follow? |
