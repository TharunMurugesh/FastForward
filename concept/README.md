# Concept, not PayPal

A mock-up for the Test Clock demo video (Fastforward is the repository's name). It shows how Test Clock could sit inside PayPal's developer
dashboard if PayPal gave permission. It is not a PayPal product and PayPal has not endorsed it.

It is not a working PayPal page. It has no sign-in, no fields for keys and no payment form, and nothing on it talks to
PayPal. Do not host it, and do not remove the "Concept, not PayPal" labels. The public demo uses the same Test Clock in a
plain frame.

To run it, start the dashboard with `npm run demo`, then in a second window run `npm run concept` and open
<http://127.0.0.1:5180>.
